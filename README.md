# Build Ai

From idea to complete building.

Build Ai is an India-first AEC / PropTech building intelligence platform. The current MVP targets residential projects in Delhi + Gurugram, starting with rectangular plots and G+0 to G+3.

## v0.5 Architecture Engine

- Site Intelligence → Buildable Envelope → Architecture workflow
- Structured programme editor
- Deterministic room-layout generation
- Adjacency-aware concept ranking
- Compliance and unresolved-regulation safeguards
- Editable CAD-style 2D plan canvas
- Candidate snapshots and score breakdowns
- Advisory AI critic actions
- Shared building-model foundation for future 3D

## Principle

**AI proposes; deterministic engines verify.**

Regulatory values are never fabricated. Unresolved authority/document/clause/effective-date information remains unresolved.

## Run locally

```bash
npm install
npm run dev
```
